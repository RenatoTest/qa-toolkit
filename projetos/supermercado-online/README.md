# 🛒 Case: Supermercado Online

Projeto de estudo de QA aplicado a um app web de supermercado online.

## 📌 Sobre o app

Aplicação web (HTML + JavaScript + Firebase Firestore) que permite:

- Visualizar catálogo de produtos
- Adicionar itens ao carrinho
- Enviar pedido via WhatsApp
- Painel administrativo para gerenciar produtos, ver pedidos e configurar o sistema

## 🎯 Objetivo do teste

Praticar técnicas de QA em um sistema real, cobrindo:

- Testes funcionais
- Testes exploratórios
- Testes de API
- Testes de segurança
- Documentação de bugs

## 🛠️ Ferramentas usadas

- Chrome DevTools (Console, Network, Application)
- Postman (testes de API REST do Firestore)
- Git / GitHub (versionamento)

## 📊 Resumo dos resultados

| Métrica | Valor |
|---|---|
| Casos de teste executados | 10 |
| Casos com sucesso | 7 |

| Bugs críticos | 2 |
| Bugs de severidade média | 1 |

## 🐛 Bugs encontrados

- **BUG-001** — Produto excluído continua contando no carrinho (Média)
- **BUG-002** — Senha do admin exposta no Console (Crítica)
- **BUG-004** — Firestore acessível publicamente sem autenticação (Crítica)
